Most browser-agent demos stop at the happy path. GhostAck starts at the failure they avoid.

The server commits an action. Before the acknowledgement comes back, I kill the browser. At this point a blind retry can duplicate a payment, an issue, or any other external effect.

This is the deployed control lab, not a prerecorded result page. I choose “kill after commit” and run it. GhostAck seals the intent, dispatches browser one, and deliberately destroys it inside the ambiguous window.

Notice the system does not retry. A second browser performs an authoritative read, finds the original receipt, and suppresses the duplicate.

The final result is one target request, one durable effect, and zero duplicates. The same lab can erase the coordinator process, collide twenty agents, or mutate the replayed intent.

Every run produces a hash-chained journal, real OpenTelemetry spans, and an Ed25519-signed proof bundle. The Solari live path runs the target in an isolated sandbox and uses two independent browser sessions.

That is GhostAck: kill the browser, recover from durable truth, and prove the action happened once.
